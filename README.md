🎓 College Club Management System

📌 Project Description

The College Club Management System is a modern, responsive, and user-friendly web application designed to simplify college club activities, student memberships, and event management.

It provides a centralized platform where students can register, explore clubs, join clubs, and participate in college events. Administrators can manage students, clubs, events, and registrations through an organized interface.

The system reduces paperwork, saves time, and improves communication between students and faculty coordinators.

🎯 Project Objectives

- Digitize college club management.
- Simplify student registration.
- Manage multiple college clubs.
- Organize college events.
- Track club memberships.
- Improve student participation.
- Provide an interactive dashboard.

🚀 Key Features

1. Dashboard

- Total clubs count.
- Club membership count.
- Total events.
- Event registration count.

2. Student Management

- Student registration.
- Student details management.
- Register number validation.
- Duplicate registration prevention.

3. Club Management

- Multiple college clubs.
- Search clubs.
- Join clubs.
- View club member counts.

4. Event Management

- Create new events.
- Event date and venue details.
- Online event registration.
- Prevent duplicate event registrations.

5. Data Management

- Browser LocalStorage.
- Automatic dashboard updates.
- Data persistence after page refresh.

⚙️ Installation and Execution

1. Download or clone the project repository.
2. Open the project folder.
3. Make sure all three source files are in the same folder.
4. Open "index.html" in a web browser.
5. Register a student.
6. Explore clubs and join a club.
7. Create events and register for them.

👥 System Users

Students

- Register their details.
- Search available clubs.
- Join college clubs.
- Register for events.

Administrators (prototype functionality)

- Create events.
- View dashboard statistics.
- Manage club information through the application data.

Note: A separate secure administrator login and backend are not implemented in this frontend version.

🔒 Data Storage

The project uses JavaScript LocalStorage to save student details, club memberships, and event registrations in the browser.

This version is a frontend prototype. A shared database and secure authentication can be added in future versions.
